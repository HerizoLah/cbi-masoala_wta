## Usage

1. Place the dataset in `data/df_17-12-2025.xlsx` or set a custom path with `DATA_PATH`.
2. Run the analysis script:

```bash
DATA_PATH="data/df_17-12-2025.xlsx" Rscript wta_analysis.R
```
